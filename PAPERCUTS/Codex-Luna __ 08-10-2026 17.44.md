# Papercuts

- The host `ajv` defaulted to an older JSON Schema draft and rejected the
  repository's Draft 2020-12 schema before task validation; use the project
  doctor/schema tooling rather than the bare default constructor.
- The Foundation image omitted `httpx`, which FastAPI's bundled `TestClient`
  requires; a session API probe failed during collection before it could supply
  a qualified RED observation.
- An ephemeral Compose container could not resolve PyPI while fetching that
  missing test dependency, even though the task-local build had already begun
  fetching its declared wheel.
- A multi-file Attempt 2 protocol patch was rejected atomically after a stale
  blank-line context mismatch; the existing task-owned protocols were reread
  before the narrower retry-state patch.
- The task-owned isolated Compose build stalled during dependency resolution
  before creating any service. Its exact process group was checked and stopped,
  then the HTTPS proof used current-source mounts in disposable containers.
- A disposable Caddy client used its Docker hostname as TLS SNI while the
  test-only Caddy site is named `localhost`; use explicit `localhost` SNI when
  probing that isolated HTTPS boundary.
- Inline shell-to-Python probe source double-escaped HTTP CRLF bytes and left
  Caddy waiting for a complete request; construct the disposable HTTP request
  from explicit byte separators instead.
- A `200` login-page check was not a sufficient readiness signal for the
  disposable proxy: an immediate login request still saw startup `502`; gate
  the two-client matrix on backend-owned missing-session `401` and make the
  expected-status assertion explicitly fail-fast.
- Bash replacement of a quoted inline Python payload malformed the source
  before the probe could connect; use fixed here-doc client invocations for
  the final two-client receipt.
- `docker exec` needs `-i` when a disposable Python client reads its program
  from stdin; without it, Python exits cleanly with no probe status.
- A final status check assumed the task card lived beside its evidence folder;
  resolve lifecycle state through `.memory-bank/tasks/index.json` before
  reading the indexed task card.
- The command runner rejected a temporary-file cleanup in a combined final
  gate; stream read-only validation output directly instead of creating and
  deleting a scratch file.

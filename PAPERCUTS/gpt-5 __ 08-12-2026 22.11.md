# Papercuts

- Broad Memory Bank discovery assumed `.memory-bank/requirements/`, but this repository has no such directory; `rg --files` emitted a distracting missing-path error. Prefer discovering existing directories first or omit optional candidates.
- A verifier-owned SQLAlchemy probe retained ORM instances across a committed session and hit `DetachedInstanceError` before exercising the claim. Retain scalar UUIDs before the session closes; the probe's `finally` cleanup still proved zero residue and an unchanged runtime singleton.
- The host has no `python` command, so a combined final JSON/Memory-Bank validation stopped before lint. Use Node for host JSON parsing or the packaged container for Python checks.

# Papercuts

- The current `face-moment:dev` image lacks transitive `httpx`, so FastAPI's
  `TestClient` cannot run task probes even though FastAPI is installed. Use the
  app lifespan directly for the disposable probe until the dependency is
  explicitly added by an authorized task.
- `compileall` cannot be used with the read-only source mount used to avoid an
  image rebuild, because it writes `__pycache__`. Compile source strings in
  memory or use a writable disposable copy instead.
- Pytest's default cache writes also fail on that read-only mount; run the
  source-mounted disposable checks with `-p no:cacheprovider`.
- The packaged application image also runs as non-root in `/app`, so pytest
  passes but cannot create its default `.pytest_cache`; use `-p no:cacheprovider`
  when a warning-free test transcript is required.

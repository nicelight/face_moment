# Papercut

- `docker image inspect ... --format '{{.Parent}}'` failed because the local
  image-inspect schema has no `Parent` key. The image IDs and repo digests were
  available through supported fields.
- One combined `apply_patch` failed on an exact handoff-context match; the
  protocol/report writes were retried as smaller patches and then succeeded.
- A globbed `rg compose*.yml` reported no matching file; the repository uses a
  different compose filename/layout, so the relevant Caddy route was checked
  directly instead.
- Host `pytest` is not installed (`pytest: command not found`); current-source
  Python checks must run through the operator image with the repository mounted.
- The operator image defaults `FACE_MOMENT_CLIENT_ROOT=/app/client`, so the
  mounted current source required an explicit `/workspace/client` override;
  without it pytest exercised the stale image bundle.

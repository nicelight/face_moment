# Packaged build delivery

- The 2026-10-06 packaged smoke stopped in the builder `apt-get install` step before any application runtime. Debian HTTP package responses had sizes inconsistent with the signed package index; the retained smoke log contains injected URL metadata and must be handled without copying its URLs or query values.
- The `python:3.11-slim-bookworm` image declares both Bookworm APT sources with `http://deb.debian.org/`. The corresponding official HTTPS index endpoints returned HTTP 200 with valid TLS from this workstation. `Dockerfile` now switches both source URI entries to HTTPS in each build stage before `apt-get update`; package selection and APT signature checks remain in place.

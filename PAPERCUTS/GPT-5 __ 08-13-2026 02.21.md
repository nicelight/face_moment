- The packaged backend image contains the focused tests invoked by pytest but
  does not expose the repository `tests` directory as an importable module to
  a mounted standalone verification script. A verifier-owned probe that reuses
  `tests.pipeline_compatibility` therefore fails before state setup and must
  carry the small stable fixture literals itself.
- A multiline shell audit can report overall success when an early static
  check fails but a later command exits zero. Inspect each emitted sub-result
  or use fail-fast semantics before treating the aggregate exit code as proof.
- Substring checks for forbidden concepts create false positives (`uuid`
  contains `ui`, `slots` contains `slo`). AST identifier/import checks are the
  reliable bounded alternative for this source-scope probe.

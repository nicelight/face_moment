# Papercuts

- Host environment has no `python` executable; use `python3` for read-only
  source probes. The failed invocation occurred before task source or fixture
  writes.
- A source-mounted mypy invocation with only separate `src` and `tests` mounts
  did not return a terminal result through the execution wrapper; mounting the
  whole repository read-only at `/app` completed normally.
- Repository-wide `git diff --check` reports pre-existing trailing whitespace
  in user-owned `notes_face_moment.md`; task-scoped diff checking is used
  without changing that file.
- Exact packaged pytest runs as image user `app` with `/app` as workdir and
  emits a non-failing `PytestCacheWarning` because `.pytest_cache` is not
  writable; test execution and task-local database cleanup still complete.
- A combined protocol patch could not apply because `verification.md` had
  already drifted from its assumed wording; inspecting current task-owned files
  before retrying keeps the handoff update narrow.
- A later aggregate evidence patch had one malformed added line and was
  rejected before any edit; split protocol and artifact patches avoid replaying
  source changes.
- A follow-up handoff patch accidentally included an invalid build-request
  context and was rejected before any edit; update the handoff and fulfilment
  note in separate patches.
- A read-only lineage probe assumed `alembic/versions` and a top-level task
  array, but this repository uses `migrations/versions` and `.tasks` in its
  task index; the command failed before any task mutation and later probes use
  the resolved paths.

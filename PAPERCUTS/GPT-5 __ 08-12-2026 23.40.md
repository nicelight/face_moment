# Papercuts

- Обычный `docker compose run backend ...` не монтирует рабочий исходный код и
  выполняет содержимое предыдущего образа; для проверки текущего изменения
  нужен явный read-only mount репозитория в `/app`.
- Даже с mount импорт сначала берёт установленный пакет из image; source gate
  должен также задавать `PYTHONPATH=/app/src`.

# Papercuts

- The Compose backend service does not mount `.tasks/`; running a task probe by
  its repository-relative path failed with `python: can't open file` until an
  explicit read-only bind mount was used.
- `docker compose build backend` can remain idle at near-zero CPU during the
  dependency-wheel download step while the existing tagged image stays stale;
  the bounded build was interrupted with exit `130` and must not be used as an
  image-gate pass.
- The repository gate command uses `python`, which is absent in this shell;
  the equivalent installed interpreter is `/usr/bin/python3`.
- The first combined Playwright camera probe did not return a useful CLI result;
  a smaller fixture-only `run-code` probe was used and passed. A disposable
  static server also reports a benign favicon 404 on the first page load.

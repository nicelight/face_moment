# Papercuts

- mb-lint не понимает percent-encoded пробелы и угловые скобки в Markdown-ссылках на файлы. Существующая ссылка из guides/local-development.md на PAPERCUTS вызывала ложный missing target; заменена точным путём в code span без изменения содержания заметки.

- Страница «Библиотека» (/staff/library, inventory/http.py::_photo_inventory_page_html) показывает только агрегаты поступлений и массовые действия над скрытыми фото; списка фотографий и их параметров в UI нет. Backend уже предоставляет выборку /api/inventory/photos и индивидуальный processing status, доступные operator/developer, но страница их не использует. Поэтому администратор не может просмотреть загруженные фотографии через библиотеку; это пробел интерфейса, а не ограничение роли. Исправлено TASK-119: отдельная страница «Медиа» площадки с превью, параметрами и оригиналами.

- Параллельный isolated Compose project конфликтует с уже запущенным стеком: compose.yaml задаёт одну подсеть 172.29.81.0/24 по умолчанию. Для тестовой базы использованы существующие FACE_MOMENT_PRIVATE_SUBNET и FACE_MOMENT_PRIVATE_DYNAMIC_RANGE с отдельной подсетью.

- PostgreSQL-backed tests проходят, но Alembic выдаёт DeprecationWarning: в alembic.ini не задан path_separator, используется legacy splitting prepend_sys_path. На текущие результаты не влияет.

- tests/diagnostics/test_attempt_investigation.py::test_operator_is_sanitized_and_current_role_is_enforced_on_every_request падает на отсутствии слова calibration во всём HTML. Общее меню уже содержит скрытую ссылку /staff/calibrations. Сбой воспроизведён отдельно с HEAD-версиями diagnostics/http.py и platform/staff_presentation.py; не вызван текущими date/time изменениями.

- /staff/spas и PUT /api/serving/spas/*/name отсутствовали в allowlist Caddy. HTTPS возвращал пустой 200, хотя backend routes и браузерные проверки с mocked routing проходили. Исправлено добавлением обоих маршрутов; проверка должна утверждать HTML содержимое, а не только отсутствие HTTPError. Добавлен regression test с настоящим Caddy.

# Замечания сессии

- В `.memory-bank/runbooks/app_guide_ru.md` описание главной утверждало,
  что публичный поиск и покупка не реализованы, хотя `client/site.html`,
  public-search и purchase contracts уже содержат эти сценарии. В рамках
  добавления информации покупателям обновлён этот абзац; незавершённое
  production-подключение платежей отмечено отдельно.

- Во время release обычная Dockerfile-сборка заново скачивала mutable Python
  base и Debian-пакеты; загрузка GCC перестала продвигаться. Для двух static
  файлов использован существующий prebuilt smoke fallback с сохранёнными
  dependencies и полной сверкой runtime-файлов. Dockerfile не менялся.
- `caddy validate` сообщает, что `header_up X-Forwarded-Proto` избыточен:
  proxy уже передаёт этот заголовок. Конфигурация валидна; в этом release
  замечание не исправлялось.

# Papercut

- `docker compose run` in this environment rejected the attempted `--no-build`
  flag (`unknown flag`); the verifier retried with the supported command while
  retaining the pinned image tag and digest.
- Host `python`/project dependencies were unavailable for the first local RED
  probe; the probe was rerun through the pinned Compose image instead.
- Read-only source overlay made `compileall` fail while trying to write
  `__pycache__`; the syntax/import check was rerun with bytecode writes disabled.
- A parallel Compose gate batch raced on the temporary `migrate` container name;
  the affected API gate was rerun sequentially with `--no-deps` and passed.

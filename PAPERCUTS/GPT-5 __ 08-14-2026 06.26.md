# Papercuts

- The host has no `python` executable, so even a syntax-only source probe must
  use an existing container image with the workspace mounted; do not assume a
  host Python runtime is available for task RED/GREEN checks.
- Mounting the workspace alone does not override the image-installed wheel;
  source probes must also set `PYTHONPATH=/app/src`, otherwise a post-edit run
  silently exercises the old packaged production code and repeats RED.

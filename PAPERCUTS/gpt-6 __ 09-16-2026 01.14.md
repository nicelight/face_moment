# Проверки мультиплощадочности

- Существующий `test_spa_rename_persists_in_staff_selectors_and_preserves_identity`
  ожидал удалённый `recent-statistics-spa-id` в библиотеке. Фактический интерфейс
  уже показывает ссылки `/staff/venue-media?spa_id=...`. Исправлена проверка
  сохранённого и экранированного имени в действующей ссылке; production UI не менялся.

- Полная сборка packaged smoke остановилась в `pip wheel`: SHA-256 скачанного
  пакета не совпал с ожидаемым. Исходный лог: `.protocols/multi-venue-packaged/smoke.log`.
  Проверки хешей не отключались, зависимости не менялись. Для проверки текущего
  source и настоящих container restarts использован производный локальный образ
  на ранее работающем `face-moment:dev`; это не подтверждение новой dependency build.

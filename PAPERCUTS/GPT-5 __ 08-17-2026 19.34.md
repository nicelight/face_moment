# Papercuts

- The verifier Playwright probe initially waited for a native `<option>` with
  the default visible-state check; Chromium exposes the option as hidden while
  it is correctly attached. The probe was corrected to wait for `state:
  attached`.
- A temporary browser fixture initially omitted the client shell mount point,
  so `app.js` had no `#client-view` and its camera state never reached the UI;
  the fixture was corrected, then the recovery path was kept in-page to avoid
  an unnecessary alternate shell.
- A fresh Playwright CLI `run-code` invocation without an already opened
  configured session failed with `The browser ... is not open`; the retry
  opened an unconfigured session and timed out before the fake-media fixture.
  The previously completed configured verifier probe remains the authoritative
  fresh browser observation; the disposable server and session were closed.

# Замеченные проблемы

- В VPS runbook после изменения FACE_MOMENT_FRP_PROXY_IP предлагался только
  Caddy reload: переменная контейнера оставалась прежней. Инструкция исправлена
  на пересоздание только edge. Серверный runbook также больше не предлагает
  запуск миграций при работающих writers и повторный запуск через depends_on.

- Live Caddy-тесты из tests/promo/test_public_edge_routes.py не могут создать
  disposable PostgreSQL database: .env.local указывает на 127.0.0.1:55432, но
  сервис не слушает этот порт. Статические и изолированные proxy-проверки
  выполняются; для полного live набора сначала нужен локальный PostgreSQL из
  runbook local-test-deployment.

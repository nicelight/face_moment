# Papercuts

- Aggregated parallel reads can exceed the direct tool-output budget and truncate otherwise successful context reads; large normative documents must be reread individually.
- `rg --files` fails noisily when any explicitly named optional directory is absent (`alembic/` here), even though the remaining paths are valid; discover repository roots before passing optional directories.
- A large multi-section `apply_patch` failed when one contextual sentence differed slightly from the drafted patch; split canonical-document refactors into smaller section-scoped patches after rereading the exact source.
- The host has `python3` but no `python` executable, while project commands run Python inside Compose; use `python3` for host-side read-only validation or the configured container command for project gates.
- Host `python3` does not include `jsonschema`; task-card schema validation needs the repository's own validator or a small read-only validator over the loaded schema instead of assuming that optional host package.
- Two short dynamic heredoc validators launched through the wrapper yielded a running-cell handle and then completed without forwarding stdout; use the simpler existing `jq`/shell probes when no durable helper script is justified.
- A naive GitHub-slug-only heading validator falsely rejects the project's exact ID-prefix locators such as `#FT-002-AC-004` and `#AD-010`, whose headings deliberately continue after the stable ID; locator validation must accept the heading's stable first token as well as a full rendered slug.
- `wait_agent` rejects sub-10-second polling even for a non-blocking status check; use its documented 10-second minimum instead of a shorter probe.

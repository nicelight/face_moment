# Papercuts

- An initial batched `/exe` context read assumed a task JSON under `.tasks/`; the authoritative card is instead under `.memory-bank/tasks/`, so the remaining requested files had to be read in a separate invocation.
- A follow-up contextual search returned no output because its first `rg` pattern was not found and short-circuited the chained reads. Subsequent reads will isolate optional searches from required files.
- The terminal relay reported a completed Compose gate script without its later gate receipts. The second run used `-T` and explicit gate boundary lines; its focused pytest failure was reproducibly visible.
- A no-op source parse command using a `mktemp` cache prefix was rejected because the bundled cleanup used `rm -rf`; the validation is retried with a pure AST parse that creates no cache directory.
- The image-packaged pytest run emitted non-fatal `.pytest_cache` permission warnings because `/app` is non-writable to the `app` user; the task test itself does not need that cache, and its actual failure was the separately recorded missing root Compose file.

# Первичная инициализация площадки

- В `compose.yaml` сервис `edge` зависит от healthy `realtime`, но `entrypoints/model_consumers.py` требует существующую общую serving revision активных SPA до запуска realtime. На пустой базе обычный вход через edge недоступен, хотя backend может обслуживать форму создания площадки. Для первичной инициализации через UI требуется согласовать изменение этой зависимости.
- В `compose.yaml` backend не получает read-only model mount, доступный realtime и background-worker. Проверка фактических SFace assets при создании первой площадки потребует того же mount для backend.

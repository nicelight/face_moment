# Papercuts

- The command wrapper reported a Docker build call complete while its child build process was still active, so a duplicate build was started before process inspection reconciled the state.
- The remaining task-owned build was also still downloading dependencies after the wrapper return; it was safely stopped before any image replacement, and the RED probe used the existing immutable image with an explicit read-only test mount instead.
- In the runtime image, mounting `/app/src` alone does not override the installed wheel; task-local source verification also needs `PYTHONPATH=/app/src`.
- A task-isolated Compose MinIO volume has no Foundation-created configured bucket, so the isolated probe must call the existing idempotent `ensure_bucket` bootstrap before it observes its task-owned prefix; the disposable volume will be removed with the project.
- The host has no `python` executable; task artifact probes must use `python3` outside the backend container.
- Host `python3` lacks the project dependencies (for example FastAPI), so the task security probe must execute in the existing backend image with explicit read-only source/artifact mounts.
- A large multi-file protocol patch had one stale context line and was rejected atomically; task protocols were reread before applying narrower updates.

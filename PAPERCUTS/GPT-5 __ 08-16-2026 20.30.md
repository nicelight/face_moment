# Papercuts

- One verifier shell-tool call failed because the JavaScript tool wrapper received a malformed object literal; the same `docker restart task058-verify-postgres` command succeeded on the immediate retry.
- One orchestration call failed because a backtick in the delegated debug prompt was interpreted as JavaScript template interpolation; the prompt was retried safely without changing repository state.
- One red-verifier polling call used a mistyped agent ID and returned `not_found`; the active verifier was unaffected and the correct ID was retained.
- One read-only shell call split papercut filenames containing spaces because the path was not shell-quoted; the same reads were immediately retried with quoted paths.
- One combined protocol apply_patch expected a wrapped line that differed from the file; it applied no changes and will be retried as smaller exact patches.
- A disposable in-network Caddy runtime probe using the image's BusyBox `wget` could not complete the internal-TLS handshake; it was stopped with no repository or long-lived service change, and packaged `caddy validate`/`adapt` remained successful.
- The first host-curl disposable Caddy probe omitted an explicit `--expose 8443` for this image/config and had no host port mapping; the exact temporary container was removed and the probe is being retried with the declared port.
- The disposable Caddy probe reached the configured backend through the new edge handler but the already-running backend image returned `404` for the new route; the exact probe container was removed, and this stale-runtime limitation is recorded as a follow-up gate rather than masked.

# Papercuts

- A multi-file `apply_patch` failed atomically because its expected handoff
  context differed by one wrapped line from the current file. Reading the exact
  numbered tail before retrying avoids broad-context mismatches.
- A truncated visual dump of the task index was insufficient to establish task
  membership. An exact machine-count query later showed zero indexed matches;
  preflight should always use the count result before describing resolution.

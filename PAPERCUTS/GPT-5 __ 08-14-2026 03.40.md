# Papercuts

- A full Compose backend build failed before task source steps because the
  Debian mirror returned a security package index with the wrong size during
  `apt-get update` (`Mirror sync in progress`). Treat this as external build
  infrastructure evidence and retry without charging the task failure budget.
- A checkpoint patch initially appended a second `current stage` entry instead
  of replacing the existing one; a follow-up patch removed the duplicate before
  any child stage was invoked.
- Authoritative task cards live under `.memory-bank/tasks/`; matching `.tasks/`
  directories hold execution evidence only. A lookup that assumed JSON cards in
  `.tasks/` failed harmlessly before rerouting to the authoritative path.

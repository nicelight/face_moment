**********************************************************************************
                        автономная ОРКЕСТРАЦИЯ тасок
**********************************************************************************

  ROLE: ORCHESTRATOR.

  ## Цель

  Доведи существующую JSON task queue через `$autopilot` в scheduler mode до terminal state.

  ## Принцип работы
  
  Работай только как control plane: readiness, sequencing, делегирование, анализ evidence, lifecycle-решения и terminal state.

  Береги контекст: загружай только минимальный governing context, authoritative queue state и критические evidence для  принятия решений. Требуй от workers компактные structured reports.

  Всю task-specific работу делегируй: исследование, `/execute`, `/verify`, `/red-verify`, tests, debugging и fixes. Самостоятельно worker work не выполняй.

   Исключение: сборку контейнеров запускай и отслеживай сам в текущей orchestrator session, без worker/сабагента и без `timeout`; дождись её завершения, периодически сообщая статус, и используй результат как scheduler evidence.

  Для каждой задачи используй независимые fresh-session workers:

  - `Implementer` — только `/execute`, запускай сабагента Codex Luna xhigh;
  - другой `Reviewer` — `/verify` и применимый `/red-verify`, запускай сабагента Codex Sol Xhigh.

  Не совмещай implementation и verification у одного worker. По умолчанию выполняй задачи последовательно.
  Если ревьювер нашел проблемы, после их устранения воркером, возвращай ответ воркера тому же самому ревьюверу, чтобы экономить токены. 

  Всякие mb-lint и прочие не тяжелые задачи запускай через Codex Luna Xhigh.

  Перед lifecycle-решением проверяй критические claims и authoritative state, но не дублируй executor checks  самостоятельно.

  Не останавливайся на исправимой worker failure: делегируй bounded fix и продолжай в рамках failure budget. Заверши  прогон только состоянием `SUCCESS` или документированным `HALT_*` с evidence и требуемым действием оператора.

Периодически пиши в чат статус работ, сообщай о каких то подводных камнях или множественных фиксах одной и той же таски, но не останавливайся.

# FT-014 — Единый выбор, тариф и бесплатные площадки

**Epic:** [EP-004](../epics/EP-004.md): публичный поиск и выбранные originals.

## Outcome

Посетитель получает понятную общую цену выбранных фото, а operator/developer управляют единым тарифом и бесплатностью площадки.

## Requirements

`REQ-PUB-003`, `REQ-PUB-004`, `REQ-PUB-008`. Frozen-core supplier также
связан с `REQ-PUB-001`/`REQ-PUB-006` (atomic paid email/profile часть,
публичный paid flow принадлежит FT-016). Registry: [requirements](../requirements.md).

## Acceptance Criteria

### FT-014-AC-001 — Combined browser selection and visible quote

- REQ: REQ-PUB-003, REQ-PUB-004
- Observable criterion: Выбор сохраняется между площадками одной ленты; sticky top показывает all-selected count (включая free), authoritative server total и «Скачать». Green free / blue paid-personal checks; select-all только доступные фото текущей площадки. Server calculation отдельно закрывается AC-002.
- Verification: Browser individual/select-all/deselect mixed venues; real quote integration и совпадение sticky total с ответом сервера.

### FT-014-AC-002 — Global marginal RUB quote

- REQ: REQ-PUB-004
- Observable criterion: Server quote считает n только paid personal по всем выбранным paid venues и применяет принятую marginal формулу Base/d1/d2/d3; n=0 даёт zero. Old special all/1,2,3+,5+,10+ pricing отсутствует. Frozen old/new order гарантия исходного AC-002 отдельно закрывается AC-006.
- Verification: n=0,1,2,5,6,20,21, mixed venues/common, half-up unit rounding/stable photo_id assignment; foreign/stale/unavailable/duplicate selections отвергаются.

### FT-014-AC-003 — Authorized venue paid/free administration

- REQ: REQ-PUB-004, REQ-PUB-008
- Observable criterion: operator/developer create/update venues с explicit strict is_free. Enabling free requires popup confirmation; cancel не отправляет mutation. Unauthorized writes denied, invalid input preserves state. Global tariff parts исходного AC-003 отдельно закрываются AC-004/005.
- Verification: Обе роли create/update paid/free; popup confirm/cancel; unauthorized/CSRF/strict-bool rejection и repository observation. Persistent is_free supplier — TASK-123, повторная migration не создаётся.

### FT-014-AC-004 — Persistent authorized global tariff provider

- REQ: REQ-PUB-004, REQ-PUB-008
- Observable criterion: serving_control хранит один global Base/d1/d2/d3 и предоставляет GET/PUT /api/serving/photo-tariff только operator/developer с existing staff session/CSRF. Invalid settings →422 без замены saved values. Provision до первой paid quote без выдуманных цен; unchanged unrelated settings.
- Verification: Real PostgreSQL owner write/read-after-new-session и migration preservation, обе роли, unauthorized/CSRF, finite/ordering/kopeck bounds, missing tariff paid quote fail-closed.

### FT-014-AC-005 — Staff tariff editor

- REQ: REQ-PUB-004
- Observable criterion: operator/developer могут увидеть/изменить единый Base/d1/d2/d3 в admin; форма использует authoritative tariff API, показывает invalid-input error и сохраняет подтверждённые значения после reload.
- Verification: Browser fixtures обеих ролей, save/reload и rejected update; API authority separately AC-004.

### FT-014-AC-006 — Frozen order core

- REQ: REQ-PUB-001, REQ-PUB-004, REQ-PUB-006
- Observable criterion: promo атомарно сохраняет authoritative выбранные composition/price/free mode и canonical order fields. Изменённые tariff/free настройки влияют только на новые orders. client_request_id unique/profile: identical replay возвращает тот же order, conflicting payload→409; paid email/profile.email/last_visit обновляются в той же transaction, free email не требует/не заменяет. ZIP начинается requested, payment not_required для zero/pending для paid без provider call. Paid browser collection/provider orchestration — FT-016, архивная выдача — FT-015/016.
- Verification: PostgreSQL repository core integration: old/new orders после settings change, все canonical fields, concurrent replay/conflict, atomic rollback/profile observation, validated membership/active/original availability и zero provider calls.

# FT-009 — Developer Log Explorer

**Epic:** [EP-003 — Explainable Diagnostics and Calibration](../epics/EP-003.md)

## Outcome

An authorized developer can search structured browser/server logs globally and
navigate from a relevant record to its correlated attempt without direct
browser access to PostgreSQL or impact on the participant-critical flow.

## Requirements

- `REQ-LOG-001`.
- Cross-cutting: `REQ-DATA-001`, `REQ-ARCH-001`.
- Registry: [.memory-bank/requirements.md](../requirements.md).

## Use Cases

- Filter structured logs by time, source, component, severity, release, message
  and correlation fields.
- Open a related attempt from a correlated log record.
- Investigate browser/server events that are not usefully discoverable from an
  Attempts-first workflow.

## Acceptance Criteria

### FT-009-AC-001 — Backend Log Explorer search

- REQ: REQ-LOG-001
- Observable criterion: An authorized developer searches structured
  browser/server logs by time, source, component, severity, release, message and
  correlation fields and navigates from a correlated record to its Attempt;
  search crosses the project backend and never connects the browser directly to
  PostgreSQL.
- Verification: Seed each searchable field, exercise combined filters and
  navigation, and inspect browser network/database topology.

### FT-009-AC-002 — Non-blocking redacted logging

- REQ: REQ-LOG-001
- Observable criterion: Log emission and diagnostic-ingestion failure do not
  block capture, search, Promo or QR. Records exclude embeddings, credentials,
  auth headers/cookies/tokens, participant names, commercial Photo originals,
  personalized session data and replay; bounded capture-derived media may be
  logged without requiring every crop or request body.
- Verification: Inject logging latency/failure through critical flows and run
  payload/redaction checks over emitted records and media references.

### FT-009-AC-003 — Technical-log expiry

- REQ: REQ-DATA-001, REQ-LOG-001
- Observable criterion: Technical log records expire after 30 days and stale
  result links cannot recover deleted log content.
- Verification: Apply cleanup around the cutoff and query current plus stale
  routes while inspecting the latest cleanup outcome.

### FT-009-AC-004 — Searchable uncorrelated events

- REQ: REQ-LOG-001
- Observable criterion: A structured event without an applicable Attempt
  correlation remains searchable without inventing an Attempt association;
  when evidence ingestion fails for a correlated flow, its core Attempt remains
  observable with an incomplete gap.
- Verification: Search correlated, uncorrelated and failed-ingestion fixtures
  and inspect navigation availability plus Attempt completeness.

## Edge and Failure Behavior

- Diagnostic ingestion failure does not block a critical participant flow; the
  core Attempt remains observable and its evidence gap is marked `incomplete`.
  Covered by `FT-009-AC-002` and `FT-009-AC-004`.
- A structured event without an applicable attempt correlation remains
  searchable without inventing an attempt association. Covered by
  `FT-009-AC-004`.
- Expired log data cannot be recovered through stale result links. Covered by
  `FT-009-AC-003`.
